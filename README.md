# Smart-Sales-Forecasting-Analysis
Smart Sales Performance Analytics and Forecasting using Excel, SQL, Python, Power BI and Machine Learning

## Project Overview

This mini project analyzes sales data to identify revenue trends, regional performance, product performance, and category contribution. It also includes sales forecasting and an interactive Power BI dashboard.

## Technologies Used

- Excel
- SQL / MySQL
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Power BI
- Machine Learning

## Project Objectives

- Analyze sales and revenue performance
- Identify monthly sales trends
- Compare revenue across regions
- Analyze product and category performance
- Perform SQL-based data analysis
- Build data visualizations using Python
- Create an interactive Power BI dashboard
- Forecast future sales using Machine Learning

## Project Files

- `sales_data.csv` – Sales dataset
- `sales_analysis.py` – Python data analysis
- `sql_sales_analysis.py` – SQL analysis file
- `Dashboard on Sales Data (mini project).pbix` – Power BI dashboard
- `.png` files – Project visualizations and dashboard screenshots

## Key Analysis

- Revenue by Region
- Monthly Revenue Trend
- Monthly Sales Trend
- Product vs Region Analysis
- Category Contribution
- Sales Forecasting
- Interactive Power BI Dashboard

## Outcome

The project provides business insights into sales performance and helps identify trends and patterns that can support better business decision-making.
